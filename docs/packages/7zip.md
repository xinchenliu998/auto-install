# 7-Zip

## 基本信息

| 项 | 内容 |
| --- | --- |
| 软件名称 | 7-Zip |
| 分组 | 必须安装（`required`） |
| 版本 | 26.04（x64） |
| 安装包 | `packages/7zip/7z2604-x64.exe` |
| 安装脚本 | [`Include/Install/7zip.au3`](../../Include/Install/7zip.au3) |
| 安装类型 | 静默安装（NSIS） |
| 用途 | 压缩 / 解压工具，装机过程中也常用于解压绿色版软件包 |

## 安装说明

- **安装方式**：运行官方安装包，带静默参数。
- **静默参数**：`/S`（NSIS 安装包，静默安装）
  - 如需指定安装目录：`/D=C:\Program Files\7-Zip`（`/D` 必须为**最后一个参数**，且路径不加引号）
- **默认安装路径**：`C:\Program Files\7-Zip`
- **主程序**：`7zFM.exe`（文件管理器）、`7z.exe`（命令行）
- **卸载方式**：控制面板卸载，或运行安装目录下的 `Uninstall.exe /S`

## 脚本实现

| 项 | 值 |
| --- | --- |
| 脚本常量 | `$ZIP7_DIR` / `$ZIP7_SETUP` / `$ZIP7_SILENT` / `$ZIP7_INSTDIR` / `$ZIP7_MAINEXE` |
| 安装位置 | `C:\Program Files\7-Zip`（走官方默认，脚本**不传** `/D`） |
| 静默参数 | `$SILENT_NSIS` = `/S` |
| 结果校验 | 检查 `7z.exe` 是否存在 |
| 超时 | `$TIMEOUT_INSTALL`（10 分钟） |

> 已安装检测与结果校验都会先查预期路径，**再查整个系统 `PATH`**，因此装在别的盘、
> 或已被别的工具带上 `PATH` 时也能正确识别为「已安装」。

## 注意事项

- 7-Zip 为 NSIS 安装包，静默参数区分大小写，使用 `/S`（大写）。
- 命令行调用示例：`"C:\Program Files\7-Zip\7z.exe" x <包名> -o<目标目录> -y`
